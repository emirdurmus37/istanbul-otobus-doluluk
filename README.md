# istanbul-otobus-doluluk
İBB açık verisiyle İstanbul'daki 841 İETT otobüs hattı için durak aralığı bazında doluluk oranı ve yolculuk süresi tahmini. Okul takvimi, trafik ve hava etkilerini hesaba katan açıklanabilir model ve web uygulaması. TÜBİTAK 2209-A ön çalışması; İBB/İETT'nin resmi ürünü değildir.
